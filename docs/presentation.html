Slide 1

The problem

Every mainstream voice assistant is cloud-only, English-first, and closed.

  • Siri, Alexa, Google Assistant — vendor cloud only. No local mode.
  • Bilingual users lose out. Russian support is second-class or missing.
  • Adding a new voice command requires a plugin ecosystem you don't control.
  • No good option for a Windows user who wants privacy and extensibility.
The gap

There is no free, open, locally-hostable voice assistant that handles RU + EN in one binary, lets you add a command in two lines, and uses a fine-tunable LLM for style.

Design principle

Every module owns one concern. The main loop is dumb — it just wires them together. Adding a new capability never touches more than two files.

Slide 3

The dispatcher — single source of truth

A dict lookup + a schema list. This is the abstraction the whole system rides on.

Adding a skill = 2 lines

  • Write a Python function that returns a short string.
  • Add one entry to SKILLS (name → callable).
  • Add its JSON schema to TOOL_SCHEMAS.
  • Done. The LLM picks it up on the next call.
13 skills shipped

Apps (open/close), web (YouTube, Google, URLs), system (time, date, CPU, battery), volume (set, get, mute, unmute).

# jarvis/dispatcher.py

SKILLS = {
    "open_application": apps.open_application,
    "youtube_search":   web.youtube_search,
    "get_time":         system.get_time,
    "set_volume":       volume.set_volume,
    # ... 9 more
}

def dispatch(tool_name, tool_args):
    fn = SKILLS.get(tool_name)
    if fn is None:
        return f"Unknown skill: {tool_name}"
    try:
        return fn(**(tool_args or {}))
    except Exception as e:
        return f"Skill {tool_name} failed: {e}"

Slide 4

Wake word and speech-to-text

Wake word · openWakeWord

  • Pre-trained hey_jarvis ONNX model — 2 MB, always-on.
  • 80 ms int16 frames from mic, ~1% CPU.
  • Threshold 0.55 (raised from 0.5 to cut false triggers on background music).
  • Buffer reset on trigger — stops Jarvis's own TTS from firing the wake word.

STT · faster-whisper

  • small multilingual model on GPU (fp16).
  • Auto language detection — no manual RU/EN switch.
  • beam_size=1, VAD-filtered — sub-second for a 5-second clip.
  • 100% correct on my own speech in 30-command test.

Slide 5

Intent routing — Gemini function calling

One API call per command. Gemini picks a tool from the 13 schemas or returns plain text.

# jarvis/llm.py

class LLM:
    def __init__(self):
        self.client = genai.Client(api_key=key)
        self.tools = types.Tool(
            function_declarations=TOOL_SCHEMAS)
        self.cfg = types.GenerateContentConfig(
            tools=[self.tools],
            system_instruction=BILINGUAL_PROMPT,
            temperature=0.2)

    def call(self, user_text):
        resp = self.client.models.generate_content(
            model="gemini-flash-latest",
            contents=user_text,
            config=self.cfg)
        # returns tool_name+args OR plain text

Why Gemini

  • Free tier, fast, one lightweight round-trip per command.
  • Native function calling — no fragile JSON prompt engineering.
  • Handles RU + EN out of the box.

Fallback path

The LLM class is abstracted — if Gemini rate-limits or the network dies, swap in llama-cpp-python behind the same interface. No caller changes.

Slide 7

Voice identity — consistent by construction

OmniVoice zero-shot clones from a fixed reference clip per language. The voice never drifts across generations.

Two reference clips

  • assets/ref_en.wav — en-GB-RyanNeural, 6.26 s. Every English response clones from this.
  • assets/ref_ru.wav — ru-RU-DmitryNeural, 7.78 s. Every Russian response clones from this.
  • Both auto-generated once by generate_ref_voices.py — no manual WAV needed to run the assistant.

Why fixed refs?

  • Consistency — same input, same voice, forever.
  • Zero friction — clones the repo, runs immediately.
  • Language-appropriate prosody — an EN ref gives awkward stress on Russian text.
  • Ethical — AI-generated Microsoft voices, not any real person.

Slide 9

Challenges and what I learned

Wake word self-triggered

Jarvis's own TTS saying "sir" fired the wake word. Fix: reset the openWakeWord buffer on every trigger. One line.

Python 3.13 broke the stack

Half of the ML deps have no 3.13 wheels on Windows. Switched to uv python install 3.11 and everything worked. Now documented as a gotcha.

SSL cert chain rejected HF

This machine's certifi bundle didn't trust HuggingFace's CA. Fix: truststore.inject_into_ssl() at every entry point. Baked in.

Gemini 2.0-flash was deprecated

Returned 404 for new callers on the day of the demo prep. Switched to gemini-flash-latest — always resolves to the current stable model.

TRL 1.x API drift

tokenizer= → processing_class=, max_seq_length= → max_length=, warmup_ratio= → warmup_steps=. Caught and fixed via smoke test before the real training run.

Would-change-in-hindsight

Start writing the dev log on day one, not day 21. Reconstruction from git history is possible but lossy.

Non-goals

Mobile app · commercial productisation · native GUI. All out of scope; each would be a separate project.
